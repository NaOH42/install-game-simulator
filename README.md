# 装游戏模拟器

一个关于旧电脑、安装进度条和收藏的浏览器增量游戏。所有游戏、下载和硬件均为游戏内模拟。

[GitHub Pages 游玩 v0.2.1](https://naoh42.github.io/install-game-simulator/) · [原站点](https://install-game-simulator.feywasp4.chatgpt.site) — 两个入口均公开免登录，支持电脑与手机浏览器。不同网址各自保存浏览器存档，不自动同步。

## 运行

在当前电脑上也可以双击 `开始游戏.cmd`，它会在后台启动本地服务并打开浏览器，不修改系统配置。

需要 Node.js 22.12+。在项目目录执行 `pnpm install`，然后 `pnpm dev`，打开显示的本地网址。

`pnpm test` 验证规则，`pnpm balance` 模拟成长，`pnpm typecheck` 检查类型，`pnpm build` 生成 `dist/`，`pnpm preview` 预览构建。

GitHub Pages 使用独立发布分支 `codex/github-pages`；源码在 `gameplay/resource-management`。构建与更新说明见 [GitHub Pages 发布](docs/github-pages.md)。

## 玩法

在装机商店中挑游戏，比较建议配置，购买后下载并安装。首次安装奖励装机点；安装完成后主动启动，运行中的游戏才持续产出。停止游戏保留安装与收藏，释放资源；卸载再释放磁盘空间，购买与收藏记录永久保留。

新存档商店最初只揭晓两款游戏；按不同游戏的首次安装数量，逐批揭晓至 4、8、12、16、20、24、28、32 款。未知卡片隐藏名称与封面，只显示解锁条件；重复安装不计数，卸载不回锁，旧存档已拥有的游戏仍然可用。全部游戏归入四类题材，不再设“梗游戏专区”。

CPU、内存、显卡和网络由运行游戏共同使用，安装任务也会争抢CPU、内存和带宽。只有联网游戏占用网络。配置不足仍可安装和运行，但效率会下降。任务管理器显示真实结算效率与占用，可随时停止游戏。

「我的电脑」每类硬件提供不同侧重的型号：优先解压还是多开、更多内存还是更多安装通道、更大硬盘还是更快写入等。已买型号可以免费换回；磁盘或通道不够的换装会被阻止，不误扣装机点。

硬件柜台以型号、价格和使用状态为主，不展示收益对比或内部计算参数，让升级回到挑选旧电脑配件的体验。

流水线允许下载与安装同时进行；自动安装助手按你设置的队列工作，不会替你花钱、卸载或启动游戏。最终安装旗舰游戏后依然可以继续收集全部 32 款游戏，包含《老头滚动条》《猫猫信条》等 8 款梗游戏。

桌面图标可按住拖到任意位置，松手保存；刷新后恢复原位置。运行中游戏会分别飘出实际收益数值，安装器中的纸飞机随当前阶段的硬件速度、资源占用和并行分配同步快慢。

手机上通过底部导航切换商店、安装、收藏和电脑，单窗口显示，正文可以上下滚动；桌面快捷方式改为可滚动网格，点击即可打开。手机布局不会覆盖电脑端保存的图标位置。

高占用会呈现老电脑的短暂迟滞、窗口残影、显存花屏或网络拥塞。效果不阻塞真实程序，停止游戏与设置入口立即响应；设置中的减少动画可关闭动态故障效果。

## 存档与声音

存档保存在当前浏览器和网址中。关闭网页后进度暂停，重新打开继续。网页仍开着但切到后台时继续推进。清除浏览器网站数据会失去本地存档；无云端同步。

旧版存档会保留余额、购买、硬件、安装与收藏；以前自动产出的已安装游戏首次读取时视为运行中，之后按新的资源竞争规则结算。

首次点击后允许播放合成声音，可在设置中分别调节音乐和音效，并减少动画。

封面由内置 image_gen 独立生成，原图与提示词在 assets/ 中；运行时全部使用项目内图片。项目不声称工具未证实的模型版本。
