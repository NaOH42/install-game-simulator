# 装游戏模拟器

一个关于旧电脑、安装进度条和收藏的浏览器增量游戏。所有游戏、下载和硬件均为游戏内模拟。

## 运行

在当前电脑上也可以双击 `开始游戏.cmd`，它会在后台启动本地服务并打开浏览器，不修改系统配置。

需要 Node.js 22.12+。在项目目录执行 `pnpm install`，然后 `pnpm dev`，打开显示的本地网址。

`pnpm test` 验证规则，`pnpm balance` 模拟成长，`pnpm typecheck` 检查类型，`pnpm build` 生成 `dist/`，`pnpm preview` 预览构建。

## 玩法

在装机商店中挑游戏，比较最低与推荐配置，购买后下载并安装。首次安装奖励装机点，留在硬盘里的游戏持续产生收藏收益。去「我的电脑」升级硬件，让以前难装的游戏更快完成。磁盘不足时可以卸载，购买与收藏记录永久保留。

流水线允许下载与安装同时进行；自动安装助手按你设置的队列工作，不会替你花钱或卸载。最终安装旗舰游戏后依然可以继续收集全部 24 款游戏。

桌面图标可按住拖到任意位置，松手保存；刷新后恢复原位置。已安装游戏会分别飘出实际收益数值，安装器中的纸飞机随当前阶段的硬件速度和并行分配同步快慢。

## 存档与声音

存档保存在当前浏览器和网址中。关闭网页后进度暂停，重新打开继续。网页仍开着但切到后台时继续推进。清除浏览器网站数据会失去本地存档；无云端同步。

首次点击后允许播放合成声音，可在设置中分别调节音乐和音效，并减少动画。

封面由内置 image_gen 独立生成，原图与提示词在 assets/ 中；运行时全部使用项目内图片。项目不声称工具未证实的模型版本。
