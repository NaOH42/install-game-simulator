# 成果卡功能与验证

日期：2026-10-12。本轮完成本地实现，不更新已发布站点、不提交 TOY 审核、不推送 Git。

## 玩家使用

从「我的收藏 → 生成成果卡」打开「我的青春电脑」。生成 1080px 宽的 PNG 长图，包含：

- 桌面留影：读取已安装快捷方式及其当前位置，在干净桌面上复现；手机端将图标整理为全景，不改写桌面布局。
- 永久收藏：只列首次安装过的游戏，保留已卸载收藏，最多展示当前全部 32 款；不会因为购买但未安装而计入收藏，不泄露未收藏游戏。
- 当前硬件：处理器、内存、显卡、硬盘、网络的已装备型号，不展示收益、占用或安装倍率。
- 可选 B站昵称和头像；拒绝授权、非 TOY 环境或 SDK 不可用时仍能生成游客卡。

可保存图片、复制配套文案；浏览器支持文件分享时提供系统分享入口。B站 App 内优先尝试官方相册保存，无法确认成功时回退浏览器下载/长按图片。预览与导出来自同一次渲染。「更新留影」重新读取此刻收藏与硬件；游戏在面板打开期间继续推进。

## TOY 接入

官方能力与来源详见 [SDK 接入说明](toy-sdk-identity.md)。`getUserProfile` 需玩家点击并经平台授权，返回昵称和头像；不提供真实 UID/MID。`toyOpenId` 不保存、不展示。仅在当前页面内存保留已授权署名，不混入游戏存档，不上传自建服务。

打开成果卡只预加载 SDK，绝不自动触发资料授权。取消展示身份会重新生成游客图，旧图在重绘期间不能导出。真实 B站账号授权及 App 相册保存仍需下一次获授权发布后的 TOY 预览/真机验证。本地模拟成功不等同于该平台验收。

## 渲染与移动端

- 封面继续复用本地生成位图；按原焦点进行裁切。
- 图片 URL 去重，最多 3 张原图并发解码；导出用缩略画布最长边 512px，解除原图引用。整体图片准备设 8 秒限时；图片失败时保留文字并提示。
- 桌面模态面板提供焦点约束、Escape 关闭及原焦点恢复；遮罩外原界面临时 inert，关闭恢复。
- 手机面板支持滚动，署名置于图片前，保存按钮固定底部，预留顶部/底部安全区。不改变电脑端窗口或图标拖动规则。

## 资料与复现

源码入口为 `src/ui/achievement-card/`，平台适配为 `src/platform/toyIdentity.ts`。成果卡按钮位于 `src/ui/App.tsx` 收藏页。

验证资料位于 `artifacts/achievement-card/2026-10-12/`：

- `fixture.html` / `fixture.tsx`：仅用于本地验证的合成进度，不读写经济存档，不打入生产包。全收藏、硬件配置样本不是用户真实游戏成果。
- `browser-check.js` / `browser-results.json`：六组浏览器窗口与下载核验。
- `identity-check.js`：仅在独立验证浏览器内替换宿主判断及 SDK 返回，合成资料有「测试玩家」前缀，不改变生产源码。
- `real-app-check.js` / `real-app-results.txt`：正常游戏入口检查。
- `card-*.png` / `ui-*.png`：导出卡片及界面截图；`tests-controlled-workers.txt`、`typecheck.txt`、`build.txt`：工程验证日志。

这些资料按 AGENTS 约定保留，不自动清理。
