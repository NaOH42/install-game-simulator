# GitHub BGM 音量修复 · 2026-10-12

音乐滑块满格后，原桌面音乐输出仍乘以 0.055 的内部增益，导致旋律明显偏小。当前共享修正把桌面音乐增益提高到 0.33，手机布局提高到 0.55；音乐、机箱声和完成音效继续独立控制，旧存档的滑块值保留。完成演出压低音乐、后台暂停与停止清理沿用原逻辑。所有声音经过公共峰值压缩器，避免混音过载。

发布源代码包含 `audioProfile.ts`、音频模块和测试，以及手机默认音量/布局切换所需的主入口和存档初始化支持。小红书适配器、打包工具、宣传素材与验收存档不进入本次源码提交。包版本保持 0.2.2，本次修复构建标识为 `github-bgm-2026-10-12`。

证据保存在 `artifacts/releases/github-bgm-2026-10-12/`：

- 当前工作区类型检查、196 项测试、真实规则数值模拟和 32 张封面检查通过。
- 真实浏览器 AudioContext 在公共压缩器之后测量：桌面音乐满格的 RMS 从 -49.86 dBFS 升至 -34.06 dBFS，相差 15.80 dB。
- 手机末段音乐、竞速/科幻满音量与机箱声混音未出现数字削波；零音量输出为零。
- 音频测试为工程输出验证，不代替不同手机扬声器上的人工听感测试。
- 构建、源码快照、页面验收和发布记录保留在同一版本目录；旧版本不清理。
