# 随机安装蓄力演出 · 2026-10-12

新增用户选定的五种临近完成效果：重力翻转、模糊像素化、显像管压缩、条尾引力、系统临界故障。效果随真实任务进度渐强，再衔接现有满格蓄力、冲击波和游戏专属像素动画。本轮仅本地实现与验证，没有部署或推送 Git。

## 演出规则

- 每个实际安装任务创建后分配一种效果，不依赖玩家是否打开对应任务。采用五种效果的随机洗牌袋，每轮各出现一次，新一轮的首项也避免与上一轮末项重复。
- 切换任务、最小化或关闭安装窗口、同标签页刷新均保持该任务的选择。表现缓存使用独立 `sessionStorage` 键 `install-simulator.anticipation.v1`；不修改经济存档或安装任务结构。浏览器拒绝缓存时使用内存回退。
- 保留全部执行中任务和最多 64 个历史任务的选择。配置损坏时安全回退；测试覆盖恢复、重复分配、随机边界和历史裁剪。
- 真实进度 75% 起出现变化，90% 后加重，99% 达到上限；沿用文件完成驱动的真实显示进度，不增加假百分比或更改速度。现有音乐渐强与机箱声音保持原规则。
- 仅当前聚焦安装窗口的主任务播放。标题栏、任务切换、队列和减弱动态按钮保持稳定可用。后台、失焦与完成时冻结演出状态；后台的游戏规则仍按已有方式推进。

## 五种效果

| 类型 | 表现 |
|---|---|
| 重力翻转 | 安装画面逐渐旋转至倒置，百分比反向旋转保持正立；按窗口实际宽高适配中途旋转，避免竖屏裁掉进度条。 |
| 模糊像素化 | 现有封面逐渐模糊、采样为粗大色块，外围碎块向条尾靠拢；进度条与百分比保持清晰。 |
| 显像管压缩 | 封面及文件区域逐渐压缩，上下弧形暗幕合拢，只留下进度区域。 |
| 条尾引力 | 周围渐暗，亮色粒子、文件碎片沿加速的弧形轨迹吸向真实条尾，形成光核和轨道。 |
| 系统临界故障 | 当前封面的局部切片错位、青红重影和短暂水平滑动逐渐增强；没有全屏频闪或真实阻塞。 |

Canvas 只采样当前游戏已加载的本地封面，不引入封面素材，不获取其他窗口内容。粒子上限 68、绘制上限 30 FPS、DPR 上限 1.5；隐藏、后台和减弱动态时停止循环，并清理监听和尺寸观察器。

## 与完成演出的衔接

任务完成时冻结当前实际显示的变换矩阵，保留满格画面。完成冲击波读取变换后的末端标记，而非默认使用外接矩形右侧，因此翻转后的条尾可从左侧释放。翻转和压缩模式复用真实满格条，不叠加方向错误的水平替代条。

所有模式沿用同一完成队列、立即发奖和可跳过机制。减弱动态设置及系统偏好均移除翻转、模糊、故障、粒子与压缩，保留清晰安装进度。
