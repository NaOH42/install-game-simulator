# 安装渐强与像素完成演出

本轮为本地玩法表现更新，未部署或推送。游戏规则、安装工作量、产出及存档格式保持原样。

## 表现

- 安装器以主题画面、纸飞机和总进度为主；移除资源占用、处理倍率、速度、阶段列表、文件计数及计时。路径流保留为低对比背景，队列折叠后按需展开。
- 当前聚焦安装任务的真实进度驱动统一强度：60% 前安静，60–85% 平滑升至 0.68，85–95% 升至 1。文件块决定的可见进度保留原有跳进规律。
- 摄像机最多放大到 1.34 倍、朝进度条右端集中，抖动最大 2.6 px；纸飞机、主题画面与日志逐渐淡出。窗口控制和队列不参与变换；临近完成时暂隐非关键成功通知，操作错误提示保留。
- BGM 节拍从 310 ms 缩短到 108 ms，逐步增加鼓点和高音琶音，限制同时发声音源数。完成时音乐退下，1.1 秒处的主冲击对应像素技能施放。
- 32 个游戏 ID 配置独立技能名、配色和变体，共 8 种动作机制。仙剑与作业使用青白衣剑侠、环绕剑阵、剑雨和冲击圈。
- 全屏演出正常 4.8 秒后消失，可按 Escape 或点击跳过。完成项按顺序排队，后续安装不重启正在播放的演出。重装不产生重复首装奖励。
- 减弱动态使用静态像素画面与 1.6 秒短淡出，不放大、不抖动；隐藏标签页暂停演出及对应声音，返回继续。跳过会停止当前庆祝音轨并恢复背景音乐。
