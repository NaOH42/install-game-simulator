# 机箱声音调整 · 2026-10-12

本轮仅调整本地声音表现：风扇随安装、运行的实际 CPU/GPU 负载升降；硬盘按下载安装阶段、运行读盘和内存换页形成机械活动，末段增加寻道密度。未修改价格、安装工作量、收益、存档格式或玩家音量设置，未上传 TOY 或其他站点。

## 声音与关联

- `src/render/machineActivity.ts` 从已有 `getSystemLoad` 与执行中的任务计算活动，独立于当前打开的窗口。排队、仅拥有和仅安装的游戏不产生工作声。
- 风扇由气流噪声、低频电机/叶片振动构成，负载控制响度、滤波开度和转速；升速和回落平滑处理。满载封顶，不随超载倍数无限增响。
- 硬盘为低沉主轴声加六种短促、阻尼化的磁头声；组合为不规则读写簇，替换跟着音乐拍点的三角波短音。声音为程序合成，不是实体硬盘录音，也不依赖外部音频文件。
- 磁盘基础活动依次为下载 `.14`、解压 `.42`、写入 `.78`、校验 `.64`。正在运行的游戏有轻读盘，内存超过容量时叠加换页活动；多任务合并并封顶。
- 写入/校验的真实总进度驱动额外密度，95% 起达到上限。加强密度而不继续提高单次敲击音量；校验阶段的活动略轻于写入，保留阶段区别。
- 机箱声受现有“音效”控制，BGM 受“音乐”控制，调度独立。完成演出时机箱声降至 38%，结束或跳过后恢复。
- 三个持续音源、最多十六个短寻道声部；后台暂停并清除寻道等待，静音停止寻道调度，停止时完整释放，恢复不补播积攒声。

## 混音验证

证据目录：`artifacts/machine-audio/2026-10-12/`。试听页 `index.html` 由 Vite 本地打开，可切换负载和音乐，也可播放各状态的 WAV。此页使用真实声音模块和演示状态，不接触游戏存档。

实际浏览器 Web Audio 渲染七段 8 秒样本，使用游戏默认音效 25%，未归一化。最终 RMS / 峰值（dBFS）为：

| 状态 | RMS | 峰值 |
|---|---:|---:|
| 待机 | -75.0 | -63.7 |
| 单款入门游戏运行 | -67.4 | -51.0 |
| 下载 | -69.8 | -50.8 |
| 解压 | -61.7 | -48.1 |
| 写入 85% | -65.3 | -47.2 |
| 校验 98% | -64.5 | -47.1 |
| 多任务满载 | -59.2 | -42.7 |

第一轮采样中持续风扇过强，最终将其上限压低；实时满载混音 RMS 从约 -51.7 调至 -58.8 dBFS，独立机箱声从 -50.6 调至 -59.2 dBFS。原始混音记录保存在 `*-initial-mix.json` 和 `initial-mix.webm`。最终实时录音为 `real-mix.webm`。

这些数据证明响应、动态范围与无削波，不替代不同扬声器/耳机上的人工听感判断。没有将录音数据称为人工试听评分。

## 工程与浏览器验证

- 全套测试：24 个文件、161 项通过；最终混音调整后再次通过受影响音频测试 20 项。
- TypeScript、生产构建通过。三条数值模拟路线完成，经济及旗舰时长与本轮前一致。
- 真实浏览器 AudioContext 验证：独立音乐/机箱、全部静音、重复启动、完成演出压低、停止释放；静音实测输出为零。
- 后台行为通过直接调用声音模块的可见性接口验证：context 时间暂停、待播寻道清空、恢复无积攒；此项不冒充操作系统物理切后台测试。
- 生产构建在 1366×768、1920×1080 与 390×844 检查安装场景：三个持续音源、实际读写声发出、页面无水平溢出和 JavaScript 运行时错误。`favicon.ico` 的既有 404 不影响游戏声音。
- 游戏场景在独立 Playwright 浏览器中使用“已运行红色警戒线、正在写入仙剑与作业”的验证存档，再由真实规则继续推进；未读写用户浏览器存档。
